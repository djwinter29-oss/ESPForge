# Native firmware unit-test setup - 2026-11-07

## Configuration

- Ruby 3.3.8, Bundler 2.6.9, Ceedling 1.1.10 with bundled Unity/CMock.
- Native GCC 15.2.0, C11, `-Wall -Wextra -Werror`.
- Dependency versions recorded in `Gemfile.lock`; suite selection in `project.yml`.
- ESP32-S3-DevKitC PROCPU, Zephyr 4.2.0, SDK 0.17.2.
- Production credential rules extracted into `credentials.c`; status serialization
  extracted into `status_format.c` with a Zephyr uptime adapter in `status.c`.

## Evidence limits

These tests execute portable production C on the host, not Zephyr on an ESP32-S3.
CMock supplies radio state and a storage-result integer; no storage implementation,
driver or card is exercised. **No SD-card test, format, write or benchmark was performed.**

Zephyr UART framing/JSON parsing and kernel/driver behavior are not covered by this
native suite. Target compilation is separate evidence, not flash/boot qualification.
Wi-Fi/BLE operation and all physical hardware validation remain pending.
See [qualification gaps](../qualification-gaps.md).
