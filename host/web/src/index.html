Wireless changes

Firmware saves boot settings, then reboots the board and briefly disconnects USB. Stop external traffic first.

Wi-Fi and Bluetooth credentials are saved with these settings. Keep a copy of the Control key; it cannot be read back. Flash credentials are not encrypted.

Untested Wi-Fi details are local only and will not be sent. They will be lost when the board reboots. Cancel and test the connection first if you want to save them.

Bluetooth control key

Generate a new key, copy it to a safe location, and save it with Boot configuration. The key authenticates control commands; it does not encrypt the Bluetooth connection. The board cannot show a saved key again.
