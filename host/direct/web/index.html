Select an ESPForge board over USB or Bluetooth

Connect through USB

Attach the DevKitC USB-to-UART connector to this computer, then select its serial port in the browser's picker. Close other serial monitors first; only one program can own the port.

Connect through Bluetooth

Scan uses this computer's Bluetooth adapter and opens the browser's nearby-device picker. The Bluetooth link is read-only: it shows public status but cannot configure Wi-Fi.

Connect to Wi-Fi

Credentials are sent once over USB-UART and stay in board RAM for this boot only. Encoding is not encryption. Changing networks requires a board reboot.
