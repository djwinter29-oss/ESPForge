USB storage ownership

Save and reboot?

Firmware saves boot settings, then reboots the board and briefly disconnects USB and Bluetooth. Stop external traffic first.

Wi-Fi and Bluetooth credentials are saved with these settings. Keep a copy of the Control key; it cannot be read back. Flash credentials are not encrypted.

Reboot board?

This immediately reboots the board and briefly disconnects USB and Bluetooth. Stop external traffic first.

Select an ESPForge device

Connect to read the saved settings.

Connect through USB

Attach your board to this computer, then select it in the browser's USB HID device picker.

Connect through Bluetooth

Scan uses this computer's Bluetooth adapter and opens the browser's nearby-device picker. Bluetooth runs only on boards with a saved control key; enter that key to connect.

Connect to Wi-Fi

Scan for nearby networks or enter a network name. A connection test does not save credentials to flash.

Bluetooth access

Generate a new key and save it with Board configuration. The key authenticates control commands; it does not encrypt the Bluetooth connection. The board cannot show a saved key again.
